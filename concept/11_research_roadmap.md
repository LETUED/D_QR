## 11.1 전제를 바꾼 결정적 발견 — Honeywell 패밀리

**US 10,235,547 / 10,846,498 / 11,449,700 / 11,727,232** ("Enhanced matrix symbol error correction",
권리자 Hand Held Products/Honeywell 계열, 공통 우선일 2016-01-26, **4건 전부 존속, 만료 2036년**):

- 후속 3건은 청구 대상을 "**a two-dimensional (2D) symbol**"로만 한정 — 정사각/QR 한정이 없어 **D_QR의 육각 기하도 문언상 포괄**
- '232 청구항 1의 "**erasure gap**"(임계값 대비 셀 반사율 간극) = exp9의 밝기 마진 신뢰도와 **수학적으로 사실상 동일**
- 패밀리 4건이 선별 방식의 모든 변형(절대 임계 '498 / 순위 '700·'232 / 개수 상한 '547)을 분담하는 **울타리(picket fence) 청구** — 선별 규칙만 바꾸는 회피 불가능
- 해외 패밀리(EP 4건, JP 4건, CN 2건)가 현재도 확장 중. **KR 멤버는 없음 → 한국 내 실시·권리화는 자유**

> **따라서 concept/10 §10.5의 "신뢰도-소거-게이트 연동 = 선행 부재" 판단은 철회한다.**
> 신뢰도→소거 연동 자체는 2016년 우선일의 선행기술이다.

**유일한 실질 회피로:** 4건 모두 신뢰도 척도를 반사율/콘트라스트(reflectance, contrast level,
erasure gap)로 한정 → 메트릭 도메인 교체. 밝기 마진 대신 **표 일치율(vote consensus)** —
서브삼각형당 N개 샘플점을 각각 하드 이진화한 뒤 표 일치 개수를 바이트 신뢰도로 사용.
이산 표 개수는 반사율 연속량과 구조적으로 다른 양이라 문언을 벗어난다 (균등론 리스크는 잔존).

**무효 방어 카드:** Forney GMD 디코딩(1966) = 신뢰도 최하위 심볼 점진 소거의 원형 →
한정해석 + 102/103 무효 논거. US 8,832,523도 추가 선행 후보.

- 출처: https://patents.google.com/patent/US10235547B2/en · https://patents.google.com/patent/US10846498B2/en · https://patents.google.com/patent/US11449700B2/en · https://patents.google.com/patent/US11727232B2/en

## 11.2 증거 요약 (계획의 입력)

**시장 (최유망 = 산업용 DPM 직접 부품 마킹):**
1. 레이저 각인·도트핀은 색 표현 불가 → **단일색이 약점이 아니라 진입 자격**인 유일 시장 (JAB 등 컬러 코드 원천 배제)
2. 저대비·국소 마모가 업계 공인 실패 모드 (ISO/IEC 29158이 별도 존재하는 이유) → exp9 소거 복호와 정확히 정합
3. 규제 강제 수요 (MIL-STD-130, FDA UDI, AS9132), DPM 시장 2023년 $2.1B → 2032년 $4.5B (CAGR 8.9%) — https://dataintelo.com/report/direct-part-marking-machine-market
4. 고정 리더(거치·통제 조명) 환경이라 카메라 파이프라인 갭이 가장 덜 치명적

**코드 갭 감사 (17건: critical 8, major 7, minor 2) — critical만:**
| 갭 | 막는 것 | 수리 |
|---|---|---|
| 검출 파이프라인 0줄 (파인더는 그려지기만 함) | 실물·논문·상용 | 15~25일 |
| 포맷 정보 0비트 (자기기술성 없음) | 실물·상용·출원(enablement) | 4~7일 |
| **파인더 배치가 실제로는 120° 회전 대칭** (hex_grid.py 주석 "비대칭"은 오류) | 실물·출원(도면 오류) | 2~4일 |
| 미검출 오복호 미방어 (사다리 k=nsym 단계 검증 여력 0) | 전부 | 2~3일 |
| **신뢰도 임계 게이트 미구현** (fine_confidence는 계산만, 게이트는 RS 예외로만) — 청구하려는 발명의 실시예 부재 | 출원 | 1~2일 |
| Honeywell 패밀리 FTO | 출원 | ✅ 완료 (§11.1) |
| 인쇄→촬영 실물 검증 0회 | 실물·논문·출원 | 5~10일 |
| QR/DataMatrix 비교 기준선 0회 | 논문 | 3~5일 |

major 중 주요: 통계 엄밀성(N=20, CI 없음), 기하 왜곡 스윕 0회, 단일픽셀 샘플링+고정 임계 128,
멀티블록 미검증(reedsolo 청크별 erase_pos 분배 — 대용량에서 사다리 깨질 수 있음), 마스킹 부재
(값 63 셀이 파인더와 동일 외형), **concept 00/03/04가 구형 컬러/정사각 텐서 설명으로 자기모순**.

## 11.5 성공 기준 (6개월)

1. **10주 내 USPTO 가출원** — 청구에 reflectance/contrast/erasure-gap 문언 0회, Honeywell 4건 인용·구별
2. exp11 표 일치율이 밝기 마진 대비 국소 오염 soft 인식률 **손실 ≤10%p**
3. **미검출 오복호 0건** + 오복호율 <10⁻³ (N≥10,000) 수치 보고
4. 포맷 링 도입 후 **외부 메타데이터 없이** 합성 왕복 100%
5. ISO 29158 합성 DPM 열화에서 DataMatrix 대비 **95% CI 비겹침 우위** 1개 축 이상
6. 인쇄→촬영 **실물 디코딩 ≥1회** + 금속 쿠폰 판독 시도
7. 가출원 시점에 비공개 제약 종료 — 이후 4개월 전부 공개 가능 작업

- ✅ 닫음: "디코더가 외부 좌표 의존" 마지막 critical 갭 — 이제 이미지 단독으로 검출→복호. 회전·스케일·완만 원근 전부 합성 검증.
- ❌ 남김 (다음 critical = **실물 갭**): 본 1,400회는 **전부 합성 장면**(프로그램 변환). 진짜 시험은 **인쇄→카메라 촬영**이며, 광학 블러·불균일 조명·종이/금속 질감·손떨림은 미검증. → **exp17(물리 열화 합성 근사)로 일부 반영, 실물 촬영은 exp18 후보로 잔존**.
- 검출 경계: 원근 >20°, 복잡 배경(육각 유사 블롭 다수), 가림 → v1(후보 랭킹 고도화) 과제.

## exp17 — 물리 기반 카메라 열화 스윕 (2026-06-13)

exp16이 남긴 "실물 갭"을 합성으로 한 걸음 좁힘. 인쇄→촬영의 물리 열화를 수식 모델로 합성(`src/exp17_physical/degrade.py`, 각 모델 출처 주석)해 검출 스윕에 주입. **목적은 무오복호 정체성이 실물 근사 열화에서도 보존되는지**.

**열화 모델(우선순위 = 현실 근접도 순):** ① Poisson-Gaussian 센서 노이즈(Foi 2008) ② 비네팅 cos⁴(Aggarwal)+정반사 글레어 ③ 디포커스 disk PSF(Mannan&Langer) ④ 선형 모션(Askari 2021) ⑤ JPEG 양자화 + (2차) Brown-Conrady 렌즈 왜곡·인쇄 도트게인. 물리 발생 순서(인쇄→광학→센서→저장)로 직렬 적용.

**결과 (1,600회, 시드 17017, 회전 0~360°+원근 0~8° 위에 열화):**

| 축 | 강건 구간 | 붕괴 시작 | 비고 |
|----|-----------|-----------|------|
| 센서 노이즈 | 강(0.06/10)까지 100% | — | 표결이 노이즈에 강함(exp15 결론 재확인) |
| JPEG | QF30까지 100% | — | 블로킹이 표 합에 거의 무영향 |
| 비네팅 | alpha 0.7까지 100% | — | 전역 Otsu가 완만 음영 흡수 |
| 렌즈 왜곡 | k1 ±0.25 99~100% | — | 어파인+사영 스윕이 약왜곡 흡수 |
| **디포커스** | **R=6px까지 100%** | — | 원판 블러는 파인더 링 방사 대칭 보존 |
| **모션 블러** | L=3 100% | **L=5 82%→L=9 56%** | 직선 번짐이 흰 링 비대칭 파괴 |
| 글레어 | — | vig+글레어 90% | 클리핑이 파인더 지움 |
| 프리셋 | clean/mild 100%, moderate 98% | **severe 0%** | 다중 열화 중첩은 v0 범위 밖 |

**전 구간 미검출 오복호 0건** — 깨지면 명시적 실패(DetectionError/RS). **핵심 통찰: 파인더 흰 링의 대칭성이 병목.** 디포커스(방사 대칭)는 R=6까지 견디나 모션(직선)은 L=5에서 무너진다 → v1 검출은 흰 링 검증을 방향 불변(모션 강건) 형상 기준으로 보강해야. 글레어는 적응 임계 전처리 필요(단 소거 판정 경로 불가침 — 검출 전처리로만).

**여전히 합성이라는 한계(사실대로):** exp17도 모델 합성이다. 진짜 검증은 실물 인쇄→카메라 촬영(**exp19**: 레이저 각인 알루미늄·종이 실촬영, 물리 치수 mm/DPI 스펙).

## exp18 — 검출 v1 모션 강건 쌍 순위 (2026-06-13)

exp17이 가리킨 모션 약점을 **진단 → 수정 → 검증**으로 닫음 (결과를 다음 연구에 반영하는 /goal 루프의 모범 사례).

**진단(단계별 잔존 계측, r=12):** 모션 블러는 데이터 셀을 번지게 해 가짜 파인더 단일을 폭증시킨다(L=0 후보 5 → L=9 18). 가짜 단일이 흰 링 검증을 통과 → 쌍이 `MAX_PAIRS=15` 상한에 포화 → hs-유사도만으로 정렬된 순위에서 **진짜 W·SE 쌍이 상위 15 밖으로 탈락**. 검출률이 떨어지는 지점이 정확히 쌍 상한 포화 순간과 일치(L=9 검출 57%).

**수정(FTO 안전, 검출 전용):** 진짜 파인더 쌍의 거리는 `r0_est = d12/(3·hs) ≈ radius−1`로 **이산 격자 반경에 스냅**되지만 무작위 번짐 쌍은 안 맞는다. 이 **격자 스냅 오차(밝기량 아닌 이산 기하)**를 쌍 순위 1순위 키로 추가하고, 어떤 격자에도 안 맞는 쌍은 드롭(가설 0개라 슬롯만 낭비), 상한 15→24. `grid_r0`를 주입받아 `finder_detect`의 CV 순수성 유지(`softdecode·spatial·consensus` 미임포트 — 아키텍처 분리 테스트 PASS).

**검증 (동일 시드 v0 vs v1, 미검출 오복호 전부 0):**

| 모션 L | v0 검출 | v1 검출 | exp17 스윕 v0→v1 |
|--------|--------|--------|------------------|
| 5 | 83% | **100%** | 41/50 → 50/50 |
| 9 | 57% | **93~96%** | 28/50 → 48/50 |
| 15 | 60% | **77~80%** | 28/50 → 40/50 |
| 글레어(vig0.5+) | 90% | **100%** | 45/50 → 50/50 (보너스) |

기하 스윕(exp16 1,400회)·타 열화 축(디포커스·노이즈·JPEG·왜곡) **회귀 0**, exp16 전체 테스트 PASS. severe 다중중첩만 여전히 범위 밖.

**남은 약점·다음 단계:** severe 프리셋(다중 열화 중첩), 모션 L≥15 잔여 손실 → 흰 링 검증을 방향 불변 형상 기준으로 보강(v2). 그리고 모든 게 합성이라는 근본 한계 → **exp19 실물 인쇄→촬영**.

## 🚨 발견 — exp10 점진적 공개 게이트의 FTO 부채 (2026-06-13)

exp16~18 검증 중 확인: **`src/exp10_progressive/decoder_v10.py`의 dual-grain 게이트가
전적으로 밝기 마진에 의존**한다. `_read_stream`이 DQRDecoderV9의 마진을 byte_conf로
소거 사다리에 투입하고, fine 공개 게이트 `fine_confidence = mean(margin)/128`도 마진이다.
이는 **Honeywell 패밀리가 선점한 반사율 기반 신뢰도→소거 메트릭과 동일** — exp11/11b/13이
표 일치율(vote consensus)+공간 소거 스윕으로 전면 교체한 바로 그 경로인데, **점진적 공개
게이트만 이식에서 누락**됐다.

**중대성:** 프로젝트의 헤드라인 정체성 기능("좋은 센서일수록 더 깊이 읽힌다")의 **유일한
구현이 FTO 침해 판명 메트릭 위에 있다.** [[project-fto-constraints]] 규칙 6(밝기 마진 금지)
위반 상태가 exp10에 잔존. 메모리의 "exp9 마진 코드 exp11 후 삭제 예정"이 exp10 의존성
때문에 미완.

**✅ exp20 (2026-06-13 완료, FTO 최우선 해소):** 점진적 공개 게이트를 마진 → **표 일치율
이산 게이트**로 이식. 새 모듈 `src/exp20_consensus_gate/decoder_v20.py` — 인코딩·렌더링
(exp10) 불변, 디코더 신뢰도·게이트만 교체. 셀 비트·신뢰도 = N점 하드 이진화 다수결 +
표차 `|2·dark−n|`(이산), fine 공개 게이트 = fine 표차 평균/N(밝기 아님), 소거 사다리는
exp11b/13 무오복호 방어(budget+퇴화 가드). 밝기 마진 판독 경로(`DQRDecoderV9._read_cell_soft`)
완전 제거.

**검증 (tests/test_exp20_consensus_gate.py 전체 PASS) + 점진적 공개 × 물리 열화 동시 실증:**
디포커스 R 증가 시 — R≤6 coarse+fine 둘 다 복호, **R=8부터 fine만 None 강등(coarse 생존)**,
fine_consensus(이산 표차) 1.000→0.899 단조 감소. **미검출 오복호 0**(coarse 절대 오답 없음,
fine은 None 우아한 강등). 노이즈 σ30에서도 consensus 유지(exp17 노이즈 강건성 재확인).
→ **헤드라인 정체성 "좋은 센서일수록 더 깊이 읽힌다"가 밝기 마진 없이 이산 표결로 구현**,
exp17 물리 열화 모델 위에서 검증. exp10은 동결(구버전 비교용), 공개·출원은 exp20 사용.

**통계 확증 (benchmarks/exp20_progressive_sweep.py, 630회):** 디포커스 축에서 점진적 공개가
가장 선명 — coarse R=12까지 100% 생존, **fine은 R=8에서 100→0% 붕괴**, 게이트 1.000→0.890
단조. 물리적 타당성: fine(12 서브삼각형=고공간주파수)이 해상도 손실에 먼저 무너지고
coarse(6삼각형)는 버텨냄. 노이즈 σ45·JPEG QF25·모션 L12는 알려진 기하에서 둘 다 강건(표결
메트릭 강건성). **전 630회 미검출 오복호 0.** 갤러리 exp20 카드가 R=8 교차를 시각화.
