# 13. 실물 검증 프로토콜 (exp19) — 인쇄→촬영

> **상태:** 실행 대기 (하드웨어 필요 — 사용자 실행 단계)
> **선행:** exp16 검출 v0 · exp17 물리 열화 합성 · exp18 검출 v1 (전부 합성)
> **목적:** 합성으로 세운 강건성 포락선이 **실제 인쇄물·카메라**에서도 성립하는지,
> 특히 **무오정정(침묵 오정정 0)**이 실물에서 유지되는지 확인.

지금까지의 모든 측정(exp16 1,400 + exp17 1,600 + exp18 회복)은 **프로그램 합성 장면**이다.
exp17이 물리 열화를 모델로 근사했지만, 모델은 모델이다. 이 문서는 합성 결과를
실물 파라미터로 환산해 사용자가 직접 실행할 **재현 가능한 프로토콜**을 정의한다.

---

## 13.1 합격 기준 (우선순위 순)

| 순위 | 기준 | 근거 |
|:---:|------|------|
| **1** | **침묵 오정정 0건** — 디코딩이 반환한 데이터는 항상 원본과 일치, 아니면 명시적 실패 | D_QR의 핵심 정체성(성공률 아닌 무오정정). 합성 13,800+3,000회 0건 |
| 2 | 권장 조건에서 복호 성공률 ≥ 90% | exp17 mild/moderate 프리셋 98~100% |
| 3 | 회전 0~360°·완만 기울기에서 위치정보 0으로 검출 | exp16 v0 자기기술 |
| 4 | 종이·금속 양 기재에서 ≥1회 복호 | 단일색 기하의 매체 무관성 |

**1순위가 깨지면(틀린 데이터를 한 번이라도 반환) 다른 모든 수치는 무의미** — 우선 봉쇄 대상.

---

## 13.2 인쇄 사양

검출 가능 최소 셀 크기 = 촬영 이미지에서 **hex_size ≈ 4.8px**(면적 하한 역산),
신뢰 복호 권장 **12~16px**, 안전 **24px**. 인쇄 모듈 크기는 "촬영 시 이 px가
확보되도록" 역산한다.

**코드 물리 크기 (프로파일 A, hex_size=16px 렌더 기준, 300 DPI 인쇄):**

| radius | 용량(A) | 코드폭(셀) | 인쇄폭 @300DPI |
|:---:|:---:|:---:|:---:|
| 8 | 71 B | 17 | ≈ 40 mm |
| 12 | 184 B | 25 | ≈ 59 mm |
| 18 | 526 B | 37 | ≈ 87 mm |
| 25 | 991 B | 51 | ≈ 120 mm |

권장 시작점: **radius 12, 약 60 mm 정사각, 300 DPI 이상**. 모듈(셀) 한 변 ≈ 2.4 mm.

**기재(substrate) 2종:**
1. **종이** — 일반 레이저/잉크젯 프린터, 무광 용지 권장(글레어↓). 도트게인 보정 불필요
   (exp17: 도트게인 1px erode까지 강건). 흑백만(단일색 정체성).
2. **레이저 각인 알루미늄** — DPM 시나리오. **글레어가 최대 위협**(exp17: 강글레어가
   파인더 흰 링을 지움). 무광 처리 또는 비스듬 조명으로 정반사 회피.

---

## 13.3 촬영 사양 (합성 포락선 → 촬영 제약)

exp16/17/18이 세운 합성 강건 범위를 촬영 조건으로 환산:

| 합성 축 | 강건 범위 (합성) | 촬영 제약 (실물) |
|--------|----------------|-----------------|
| 회전 | 0~360° 100% | 제약 없음 — 아무 방향 |
| 스케일 | 0.5~2× 100% | 코드가 프레임의 30~80% 차지 |
| 원근 기울기 | ≤20° 100%, 25° 저하 | 정면 ±20° 이내 권장 |
| 디포커스 | ≤6px 100% | **초점 확실히 맞추기**(탭 포커스) |
| 모션 블러 | ≤5px 100%, 9px 96%(v1) | 손떨림 최소 — 셔터 1/60s↑ 또는 거치 |
| 조명 비네팅 | alpha 0.7까지 100% | 완만한 밝기 기울기 허용 |
| **글레어** | vig+글레어 100%(v1) but 강글레어 위험 | **정반사 회피 — 광원 비스듬, 무광 매체** |
| JPEG | QF30까지 100% | 저장 화질 무관(거의) |

**핵심 촬영 수칙:** ① 초점 고정 ② 손떨림 억제 ③ 정반사(글레어) 회피.
나머지(회전·거리·압축·완만 조명)는 관대하다.

---

## 13.4 측정 매트릭스

각 셀 **N ≥ 30** 촬영, 시드/조건 라벨 기록. `dqr_decode` CLI(메타데이터 없는 PNG
자동 인식)로 복호 → {성공 / 명시적 실패 / **침묵 오정정**} 분류.

| 조건군 | 변량 | 수준 |
|--------|------|------|
| A 기준 | 정면·정초점·거치 | 1 |
| B 회전 | 코드 회전 | 0·90·180·270° + 임의 |
| C 거리/스케일 | 프레임 점유율 | 30·50·80% |
| D 기울기 | 정면 대비 각도 | 0·10·20·30° |
| E 손떨림 | 거치 vs 손촬영 | 2 |
| F 조명 | 균일·사선·역광·정반사 | 4 |
| G 기재 | 종이 vs 알루미늄 | 2 |

**필수 기록:** 각 촬영의 원본 페이로드, 복호 결과, 분류. 침묵 오정정은 **이미지 보존**
(재현·디버깅용). 실패 모드 3분류(검출 실패 / 샘플링 실패 / RS 실패)도 기록 → v2 입력.

## 13.5 장비 (1인 저비용)

- 프린터: 가정용 레이저(흑백, 600 DPI면 충분) 또는 잉크젯 무광 용지
- (선택) 레이저 각인기 외주 — 알루미늄 쿠폰 5~10매 (수만 원, exp17 로드맵 기존 계획)
- 카메라: 스마트폰(1200만 화소면 충분), 탭 포커스
- 보조: 자/캘리퍼(물리 치수 검증), 삼각대/거치대(모션 통제군), 무광 배경지
- 조명: 자연광 + 사선 조명(글레어 통제), 정반사 회피용 편광판(선택)

## 13.6 합성↔실물 대조 (검증할 예측)

exp17/18이 만든 **반증 가능한 예측** — 실물이 어긋나면 모델을 고친다:

1. **무오정정 0 예측**: 어떤 실물 열화에서도 틀린 데이터 반환 0. ← 가장 중요, 깨지면 즉시 조사.
2. **디포커스 관대 / 모션 취약 예측**: 초점 약간 나가도 복호되지만 손떨림엔 약함
   (디포커스 방사대칭 vs 모션 직선 — exp18 진단). 실물에서 비대칭 확인되면 모델 타당.
3. **글레어 = 금속 최대 위협 예측**: 알루미늄 정반사에서 검출 실패 집중.
4. **종이 도트게인 무해 예측**: 일반 인쇄 번짐은 복호에 영향 거의 없음.

대조 결과는 exp17 degrade.py 파라미터 보정에 환류 → 합성 모델 정밀도 향상(루프).

## 13.7 FTO·비공개 주의

- 실물 데이터는 **가출원 enablement 보강**용(합성 전용 출원의 약점 보완, concept/11 §11.6).
- 실촬영 이미지·코드 디자인은 **출원 전 외부 공개 금지**(신규성 상실). 인쇄물을 제3자에게
  보여주는 것도 공개로 해석될 수 있음 — 본인 실험만.
- 검출/촬영은 위치 추정·입력 생성일 뿐, **소거 판정 경로(밝기 마진 등) 불가침** 유지
  (Honeywell 울타리 — concept/10·11, [[project-fto-constraints]]).
