## 9.1 진단 — 무엇이 어긋났는가

### 9.1.1 핵심 자산 (지킬 것) ✅

| 자산 | 출처 | 왜 자산인가 |
|------|------|-----------|
| 순수 기하 단일색 | exp4 | 인쇄·조명·화이트밸런스에 불변. 색상 의존 경쟁기술과 정반대 |
| 점진적 공개 | exp7 | 센서 등급에 따라 더 깊이 판독. 기존 바코드에 없는 신규성 |
| 채널 독립 ECC | exp2 | 부분 손상에도 graceful degradation |

### 9.1.2 약점 (직시할 것)

```
약점 1. 밀도↑ = 인식률↓
  QR이 시장을 이긴 축은 '용량'이 아니라 '보편 판독성 + 오염 내성'.
  셀당 비트 6→12→16 증가 → SNR 여유 감소 → 현실 인식률 하락.
  스마트폰 카메라 ~20dB SNR → 신뢰 가능 ≈ 6.7비트/측정 (Shannon).

약점 2. '차원' 개념 4종 혼재 → 과장청구(over-claim) 위험
  - 기하 분할 : 진짜 밀도 이득     (핵심)
  - 프랙탈    : 해상도 한계 k≈2~3  (핵심, 단 제한적)
  - 링크 체인 : 사실상 URL = 외부저장 (응용, 별개)
  - 물리 Z-depth : 3D프린터·LiDAR 필요 (폐기 후보)
  → "16차원"은 이 4개를 뭉뚱그린 표현. 심사·리뷰의 1순위 공격 지점.

약점 3. 진짜 한계의 위치
  한계는 '차원 수'가 아니라 '매체 해상도 × SNR'.
  차원은 한계를 재배치(rearrange)할 뿐 제거(remove)하지 못한다.
```

### 9.1.3 중심 모순 ⚠️

```
D_QR 철학:  오프라인 · 자기완결 (QR의 본질)
        ⟷  충돌
링크 체인:  외부 링크로 "무한 차원"

링크 체인을 네트워크 링크로 구현하는 순간
D_QR = "QR + 클라우드" → 이미 존재하는 평범한 패턴, 차별성 소멸.
```

## 9.2 해결방안

### 9.2.1 [해결 1] 밀도를 가변 프로파일로 — SNR 벽 우회

밀도를 고정값으로 고집하지 않고, QR이 버전(1~40)·ECC레벨(L/M/Q/H)로 환경에 맞춰
선택하게 한 전략을 그대로 차용한다 (ISO/IEC 18004).

```
프로파일 A (인쇄·실외, 저 SNR): 6비트/셀, ECC 30%  → 인식률 우선 (primary 삼각형 6개)
프로파일 B (화면·근접, 고 SNR): 12비트/셀, ECC 20% → 밀도 우선 (sub 삼각형 12개)
```

선택 기준은 Shannon 한계로 정당화된다:

$$C = B \log_2\!\left(1 + \frac{S}{N}\right) \quad\text{[비트/측정]}$$

| 매체 | 추정 SNR | $C$ | 권장 프로파일 |
|------|---------|-----|-------------|
| 실외 인쇄 + 폰 | ~15 dB | ~5.0 bit | A (6비트, 여유 ECC) |
| 실내 화면 근접 | ~25 dB | ~8.3 bit | B (12비트) |

**검증현황:** ✅ Shannon 한계 적용 정확. 프로파일 메타데이터 내장으로 디코더 자동 선택.

### 9.2.2 [해결 2] soft-decision 복호 — 버리던 마진을 회수

현재 디코더의 손실 지점 (decoder_v6.py:45):

```python
bit = 1 if brightness < self.threshold else 0   # ← 밝기 마진을 즉시 버림
```

밝기가 임계값에서 얼마나 떨어졌는지(마진 = $|b - \tau|$)가 곧 **신뢰도**다.
마진이 작은(애매한) 셀을 **소거(erasure)** 로 표시하면, Reed-Solomon은
오류 대비 2배의 소거를 정정한다:

$$2 \cdot e + s \le n_{sym} \qquad (e=\text{오류 수},\ s=\text{소거 수})$$

- 오류만: 최대 $\lfloor n_{sym}/2 \rfloor$ 정정
- 위치를 아는 소거: 최대 $n_{sym}$ 정정 (**2배**)

즉 "어느 바이트가 의심스러운지"를 밝기 마진으로 알아내 소거로 넘기면,
**ECC를 늘리지 않고 같은 인쇄물에서 정정 능력이 최대 2배**가 된다.

**검증현황:** ✅ exp9 구현·실측 완료 (2026-06-12, `outputs/exp9_benchmark_report.md`):
- 국소 오염 70패치: hard 25% → **soft 100%** (+75%p, 프로파일 A)
- 국소 오염 40패치: hard 15% → **soft 95%** (+80%p, 프로파일 B)
- 가우시안 노이즈 천이 구간: +25%p (σ=115, A) / +25%p (σ=110, B)
- 전역 블러: 이득 없음 — 소거는 *위치를 아는* 손상에만 유효 (이론과 정확히 일치)

**근거:** Reed-Solomon 소거 정정 원리 — https://en.wikiversity.org/wiki/Reed%E2%80%93Solomon_codes_for_coders

### 9.2.3 [해결 3] 링크의 재정의 — 모순 해소

링크 체인을 **"외부 네트워크 링크"가 아니라 "동일 매체 내 물리 계층 링크"** 로 한정한다.

```
나쁜 링크체인:  C₂ → URL → 클라우드            (오프라인 깨짐 = QR+클라우드)
좋은 링크체인:  C₂(겉) ⊃ C₃(속, 같은 코드)     (오프라인 유지, 센서가 키)
```

이렇게 하면 점진적 공개(exp7)와 동일 메커니즘이 되어 **철학 모순이 사라진다.**
스마트폰 = 겉 계층(C₂), 고해상 스캐너 = 속 계층(C₃·C₄)까지 같은 종이에서 해제.

**물리 정당성 (단, 무한 아님):** 2D 경계가 더 깊은 정보 계층을 담을 수 있다는 것은
Bekenstein bound로 뒷받침되나, 동시에 면적 × 해상도로 **상한이 존재**함을 명시한다.
— https://en.wikipedia.org/wiki/Bekenstein_bound

**검증현황:** ✅ 철학 일관성 회복. 무한 용량 주장은 폐기, "계층적 유한 용량"으로 정정.

### 9.2.4 [해결 4] 물리 Z-depth 강등 — 폐기 대신 옵션 채널

Z-depth(exp5)는 3D프린터·LiDAR가 필요해 범용성이 없다 → **핵심에서 제외**.
단 완전 폐기 대신 점진적 공개의 최상위 선택 채널로 편입:

```
C₂ 기하(모든 카메라) → C₃ 미세계층(고해상) → C₄ Z-depth(전용 스캐너, 선택)
```

여권·명품 정품인증 등 고가 보안 응용 전용. **범용 경로에선 절대 요구하지 않음.**

**검증현황:** ⚠️ 보존하되 비핵심. 범용 디코딩 경로에서 분리.

## 9.3 정체성 재정의

> **"더 많이 담는 코드"가 아니라**  
> **"오염에 강하고, 좋은 센서일수록 더 깊이 읽히는 단일색 기하 코드"**

| 메커니즘 | 정확한 정의 | 위상 |
|---|---|---|
| 기하 분할 (exp4/6/9) | 셀당 비트 수 | **핵심 청구항** |
| 점진적 공개 (exp7) | 해상도 계층 판독 | **핵심 청구항** |
| soft-decision (exp9) | 마진 회수로 정정력 2배 | **핵심 기술** |
| 링크 (exp8) | 동일 매체 계층 참조 | 응용 |
| 물리 Z-depth (exp5) | 전용 스캐너 옵션 | 부록/장기 |
