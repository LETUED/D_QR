# exp12 침묵 오정정 3층 방어 — 검증 보고서

## 방어 구성

- **1층 사다리 상한**: 최종 소거 단계 nsym → nsym-2 (예: nsym=51 사다리 [0, 17, 34, 51] → [0, 17, 34, 49]). 풀소거(nsym)는 미지수=방정식이라 연립이 항상 풀려 비소거 위치의 오류가 그대로 '성공'으로 통과하는 구조적 침묵 오정정 경로 — 이를 제거.
- **2층 재인코딩 대조** (CRC 아님 — FTO 제약 3 준수): 복호 결과를 RSCodec으로 재인코딩해 수신 코드워드와 비교, 불일치 위치가 (소거 표시 ∪ RS 보고 정정 위치)를 벗어나면 실패 처리. 결정론적.
- **3층 신뢰도 게이트**: fine 스트림 평균 바이트 vote 신뢰도 (exp11 표결 메트릭, N=9) < **0.405** 이면 RS 시도 자체를 생략하고 fine=None. 이산 표 개수만 사용 — 밝기 연속량 불사용 (FTO 제약 1 준수).

## ① 코드워드 레벨 시뮬레이션 (N=10,000, seed=42)

- 구성: exp10 fine 스트림과 동일 (nsym=51, data 206B, 코드워드 308B → reedsolo 2청크 경로 포함)
- 오류 주입: 시행당 무작위 위치 10~80개 바이트 XOR (비영 보장)
- 신뢰도 모델: 오류 바이트 U[0,60], 정상 바이트 U[20,128] — 구간을 겹쳐 신뢰도가 오류 위치를 완벽히 못 가리키는 실측 상황(블러·오염) 모사

| 결과 | 방어 전 | 방어 후 (1+2층) |
|------|---------|------------------|
| 정상 복호 (correct) | 3,648 (36.5%) | 3,648 (36.5%) |
| **침묵 오정정 (wrong)** | **237 (2.37%)** | **84 (0.84%)** |
| 실패 반환 (fail) | 6,115 (61.2%) | 6,268 (62.7%) |

- **오정정률 (전체 시행 대비)**: 방어 전 237/10,000 = 2.37e-02 → 방어 후 84/10,000 = 8.40e-03
- 오정정 차단: 방어 전 오정정 237건 중 208건이 방어 후 실패(차단)로 전환
- **false reject (방어 비용)**: 방어 전 정상 복호였다가 방어 후 실패로 바뀐 시행 0/10,000 (< 1e-04)
- **신규 오정정 (방어가 만든 wrong)**: 방어 전 correct였다가 방어 후 wrong이 된 시행 0/10,000 (< 1e-04)
- 소요 시간: 281s

### 잔존 오정정 분석 (방어 후에도 wrong)

- 발생 단계: 전부 소거 [49]개 단계 (사다리 최종 단계)
- 주입 오류 수 범위: 30~78개 (절반거리 25개를 한참 넘는 영역)
- 메커니즘: 최종 단계에서도 RS가 남은 신드롬 여력을 오류 탐색(BM)에 마저 소진하면(보고 정정 수 > 소거 수) 검증 여력이 다시 0이 되어 다른 유효 코드워드로 수렴할 수 있다 — 보고된 정정 위치 안의 불일치라 2층 대조도 통과한다 (RS 반경 밖 복호의 본질적 한계). 후속 후보: errata 예산 검사 (청크별 2·오류+소거 ≤ nsym-2 강제).
- 전이표의 fail→wrong 55건: 구동작은 풀소거(nsym) 단계에서 예외를 던지고 끝났지만, 새 최종 단계(nsym-2)는 BM 오류 탐색 여지가 있어 오히려 잘못된 코드워드로 '성공' 수렴한 경우. 사다리 상한은 '항상 해가 존재하는' 풀소거 경로를 제거할 뿐 BM 소진 경로까지 막지는 못한다 — 총량은 그래도 순감소(237→84)이며, 일소하려면 위 errata 예산 검사가 필요.

## ② 3층 게이트 캘리브레이션 (블러 스윕 실측)

- 마지막 정상 복호 vote 신뢰도 (blur 5.5px): **0.4199**
- 침묵 오정정 지점 vote 신뢰도 (blur 6.0px): **0.3911**
- **임계값 = 중간값 0.405** (decoder_v12.FINE_GATE_THRESHOLD)

> **정직 고지 — 비단조성**: vote 신뢰도는 블러에 단조 감소가 아니다. 6.5px 이상에서 0.41~0.44 고원이 형성돼 임계를 넘는다 (exp11 블러 절벽과 동근원 — t=0.5 외곽 샘플이 이웃 번짐을 흡수해 표가 안정적으로 갈라짐). 따라서 3층 게이트는 단독 방어가 아니며, 고원 구간에서 RS가 시도되더라도 1·2층이 결정론적으로 차단한다 (아래 표의 1+2층 열 참조). 게이트의 효용은 ⑴ 관측된 오정정 지점(6.0px)의 사전 차단과 ⑵ 저신뢰 구간에서 RS 시도 비용 절약이다.

- 1·2층: 신뢰도 메트릭과 무관한 대수적 방어 (사다리 상한·재인코딩 대조) — CRC 불사용 (제약 3).
