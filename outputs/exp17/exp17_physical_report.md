# exp17 — 물리 기반 카메라 열화 스윕 결과

- 페이로드: "exp17 물리 카메라 열화 — 인쇄→촬영 간극 검증" (63B), 프로파일 A, r=12, nsym=76, 기준 hex_size=24px
- 조건당 N=50, 시드 17017 고정 (재현 가능), 총 1600회
- 기하 배치: 회전 0~360° + 임의 오프셋 + 원근 0~8° **위에** 물리 열화 직렬 적용
- **미검출 오복호: 0건** — 검출/복호 실패는 전부 명시적 예외

## 무엇을 시험했나 (exp16과의 차이)

exp16은 이상적 기하 변환만 거친 장면이었다. exp17은 그 위에 인쇄→촬영의
물리 열화를 합성: 디포커스 disk PSF, 손떨림 선형 모션, 비네팅(cos⁴ 근사)+
정반사 글레어, Poisson-Gaussian 센서 노이즈, Brown-Conrady 렌즈 왜곡, JPEG
양자화, 인쇄 도트게인. 각 모델의 수식·출처는 src/exp17_physical/degrade.py 주석.

## 해석 (정직)

- **미검출 오복호 0 유지**: 모든 열화·강도에서 디코더가 틀린 데이터를 반환한 적 없음 — 깨지면 명시적 실패(DetectionError/RS). 무오복호 정체성이 물리 열화에서도 보존.
- **강건 구간**: 약~중간 열화(mild/moderate 프리셋, 디포커스 ≤3px, 모션 ≤5px, JPEG ≥50, 렌즈 왜곡 전 범위)에서 검출·복호 높게 유지.
- **붕괴 구간(정직 고지)**: 디포커스·모션이 파인더 흰 링과 (서브)삼각형 경계를 뭉개면 후보 자체가 사라져 검출 실패 → exp15 블러 완패와 동일한 특성 크기 트레이드오프. severe 프리셋은 다중 열화 중첩으로 v0 범위 밖.
- **조명**: 전역 Otsu가 완만한 비네팅은 흡수하나, 강한 글레어(클리핑)는 파인더를 지워 검출 저하 — 적응 임계가 v1 과제(단 소거 판정 경로 불가침, 검출 전처리로만).
