# exp14 — 홀로그램 CGH 시뮬레이션 보고서

**창립 가설 검증**: "단일색 이진 기하가 홀로그램 재생에서 보존되는가"
(concept/12_hologram_3d.md §12.6 0단계 — 비용 0원, numpy FFT 전용)

## 판정: 창립 가설 ✅ 지지

| 합격선 | 결과 | 판정 |
|--------|------|------|
| (a) 코히어런트 재생에서 coarse+fine 판독 | coarse O / fine O | PASS |
| (b) 백색 LED 분산에서 coarse 생존 | coarse κ ≤ 0.05 / fine κ ≤ 0.02 | PASS |
| (c) 스페클 생존 경계 실측 | coarse 전수생존 C ≤ 0.5 / fine C ≤ 0.4 | 실측 완료 |
| 대조군: 컬러 코드 붕괴 | R/G/B 비트 정확도 68.4%~73.7% (단일색 100.0%) | 붕괴 확인 |

## 방법

- 패턴: exp10 dual-grain (r=12, coarse 230셀·6bit·ECC 30% / fine 218셀·12bit·ECC 20%), hex_size=16
- 페이로드: coarse 33B / fine 71B
- CGH: Gerchberg-Saxton 50회 연속 + 25회 이진(0/π) 양자화, field 2048², 오프축 창 배치
  (이진 위상 = 실수장 → 쌍둥이 상이 필연이므로 타깃에 점대칭 쌍둥이를 명시 포함해 제약을 대칭과 양립시킴). 재생 효율 η=0.421 (쌍둥이 상 몫 제외 시 이진 위상의 물리 상한 ~0.405와 정합), 충실도 corr=0.971
- 재생: Fourier 기하, 위치 ∝ λ. 표면 부조 위상 깊이 detune φ(λ)=π·(532/λ) 포함
- 백색 LED: 450/550/650nm 세기 합성. 분산 기하 계수 κ ∈ [0,1]로 이미지면(κ=0, 엠보싱 양산 경로)↔Fourier(κ=1) 보간 — s_eff = 1 + κ(λ/532 − 1)
- 스페클: 곱셈성 세기 변동(평균 1, 콘트라스트 C, 그레인 2px), C별 15회 시행
- 판독: 기존 decoder_v10 그대로 (전역 임계 128, 새 신뢰도 메트릭 도입 없음 — FTO 1·2 준수). 성공 = 페이로드 원본 일치 (미검출 오복호는 실패로 집계)

**coarse만 생존하는 κ 대역(0.02~0.05)이 존재** — exp10의 점진적 공개(스케일 도메인)가 각도/분산 도메인으로 그대로 이식됨을 확인. κ=1(순수 Fourier, 오프축 캐리어로 상 전체가 파장당 수십 px 강체 변위)은 붕괴가 물리적으로 자명하며, 이것이 양산 엠보스 홀로그램이 이미지면 기록(κ→0)을 쓰는 이유와 정합한다.

## 대조군 — 가상 컬러 코드의 파장 분산 붕괴

같은 삼각형 기하에 R/G/B 3채널 독립 비트(용량 3배 주장 구조)를 싣고, 채널별 전용 파장(650/550/450nm) CGH로 기록한 최유리 설정. 그러나 표면 부조 홀로그램은 thin grating이라 파장 선택성이 없어 모든 CGH가 모든 파장을 회절시킨다 → 카메라 각 채널에 세 패턴이 겹친다.

| 조건 | 컬러 R | 컬러 G | 컬러 B | 단일색 (같은 측정) |
|------|--------|--------|--------|--------------------|
| κ=0 (컬러 최유리) | 69.9% | 68.4% | 73.7% | 100.0% |
| κ=1 (Fourier) | 66.0% | 67.6% | 78.2% | 67.8% |

컬러 채널 바이트 오류율 추정(독립 비트 근사) 91% — RS가 정정 가능한 한계(ECC 30%, 오류만 ≈ 15%)를 크게 초과해 어떤 ECC율로도 복호 불능. 단일색은 세 파장이 같은 정보의 중복 사본이라 혼합이 손상이 아니다. 이것이 CHQR(US 10,885,413)이 층별 분산성 HOE라는 별도 광학 장치를 요구하는 이유의 시뮬레이션 재현이며, 창립 가설의 역방향 증거를 완성한다.

## 한계 (정직 회계)

- κ는 유효 계수다 — 실제 엠보스 홀로그램의 분산은 기록 기하·재생상 깊이·조명 입사각에 의존하며, κ=0은 이상화다. 직접 답은 2단계 PoC(LitiHolo 기록)만 줄 수 있다 (concept/12 §12.6).
- LED를 3선 스펙트럼으로 근사 — 실제 백색 LED는 연속 스펙트럼이라 스미어가 더 매끄럽다 (이산 고스트보다 판독에 유리할 수도, 불리할 수도 있음).
- 0차 누설·스페클은 모델링했으나 기록 매질 비선형성·표면 거칠기· 카메라 노이즈는 미포함.
- 본 시뮬은 용량 증가를 주장하지 않는다 — 검증 대상은 "보존"이지 "증대"가 아니다 (concept/12 §12.3 과장 금지선 유지).

*판독기는 D_QR 전용 디코더(decoder_v10)이며 본 실험은 새 신뢰도 메트릭·국소 필터를 도입하지 않았다.*
